## Описание

Расширение для Visual Studio Code. Оно показывает в строке состояния,
сколько дней, часов и минут осталось до дедлайна проекта. Значение обновляется
раз в минуту.

## Настройка дедлайна

Открой настройки VS Code, найди `Deadline Status: Deadline` и укажи дату в формате
`ГГГГ-ММ-ДДTчч:мм:сс`, например `2026-12-01T23:59:00`.

## Запуск из исходников

Открой папку проекта в VS Code, нажми `F5` и выбери окно Extension Development Host.
Для установки даты в конкретном проекте добавь `.vscode/settings.json`:

```json
{
  "deadlineStatus.deadline": "2026-12-01T23:59:00"
}
```

## Как работает расширение

При запуске расширение создаёт элемент строки состояния. Функция `update` читает
дату из настроек, вычисляет разницу с текущим временем, переводит секунды в дни,
часы и минуты и обновляет надпись. Таймер вызывает эту функцию каждую минуту.
При закрытии окна таймер очищается.
